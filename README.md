# Calen-Tarefa 
O Calen-Tarefa é uma aplicação web do tipo SPA desenvolvida para o planejamento, organização e acompanhamento de tarefas diárias, permitindo gerir prazos e categorizar atividades com tags personalizadas.


## Tecnologias Utilizadas
- **Back-end:** Python, Flask, SQLite, JWT (Flask-JWT-Extended), Flask-CORS, Requests.
- **Front-end:** HTML5, CSS3, JavaScript e Componentes de Calendário.
- **APIs Externas:** Nager.Date API (para consulta de feriados públicos).
